# MyGo Video · 界面设计说明

界面稿：`index.html`（可直接打开，或用 `python3 -m http.server 4311 --directory designs` 后访问 `/mygo-video/index.html`）。

## 目标

做一个"影院黑 + 原生玻璃"的桌面视频客户端：像 mygo-music 一样安静、克制，但内容更大、更暗，强调色跟着影片走。

- **假设**：桌面端（macOS 优先，兼顾 Windows/Linux），1440×920 默认窗口，最小 1080×700。
- **真实数据**：所有片名、剧集、演员都是虚构占位，避免版权问题。
- **占位图**：海报/剧照用 CSS 生成的抽象"光影占位"，不是真实图片。真实实现使用插件/刮削返回的图片。

## 信息架构

```
侧边栏（232px）
├─ 返回 / 前进 / 搜索（⌘F）
├─ 源切换（本地 / 腾讯 / 优酷 / B站 / WebDAV / Jellyfin）
├─ 首页 / 我的片库 / 发现
├─ 追剧（最近 3 部）
├─ 源与插件 / 设置
└─ 账户
```

页面：首页 → 详情 → 播放（全屏覆盖层）；搜索、片库、源与插件为并列页。

## 视觉系统

| Token | 值 | 用途 |
| --- | --- | --- |
| `--bg` | `#0d0e11` | 内容底 |
| `--panel` | `#14161a` | 卡片/列表 |
| `--sidebar` | `#101216` | 侧栏 |
| `--text` | `#f2f3f5` | 主文字 |
| `--muted` | `rgba(235,235,245,.56)` | 次要 |
| `--faint` | `rgba(235,235,245,.3)` | 辅助 |
| `--line` | `rgba(255,255,255,.07)` | 分隔 |
| `--accent` | `#e7a25e`（运行时从海报取色） | 强调 |
| `--radius` | `12px` | 卡片/层 |

- 字体：`-apple-system, "SF Pro Text", "PingFang SC", "Noto Sans SC"`；标题 600–650，正文 12–14。
- 间距按 4 的倍数；海报 2:3，剧照 16:9。
- 动效：海报 hover 上浮 3px（220ms）、播放页控制条 3.2s 无操作淡出、抽屉 300ms 缓动、弹幕匀速（80–104 px/s）。

## 六屏

### 01 首页
继续观看大卡（16:9 + 进度 + 一键续播）→ 追剧横排（更新角标、进度条）→ 今晚看什么（16:9 大卡）→ 最近添加。

**设计意图**：首屏只回答"接着看什么"，不做信息流堆叠；"追剧"是最好的留存入口。

### 02 详情
剧照背景 + 海报 + 标题/评分/规格 + 继续观看（带集数）+ 加入追剧 + 从第 1 集开始；分季分集（已看勾选 / 当前集高亮 / 进度条）；简介 + 演职员 + 来源与弹幕状态。

**设计意图**：播放按钮永远指向"下一件该看的事"，而不是第 1 集。

### 03 搜索
大搜索框 + 源标识 + 类型 chips + 影片网格 + 人物 + 最近搜索。

**交互**：输入即时过滤；⌘F 聚焦；结果按源聚合（切换源重搜）。

### 04 片库
追剧 / 收藏 / 历史 / 下载；追剧网格按更新时间排序；最近观看横向列表。

### 05 源与插件
每个源一张卡：图标、名称、**能力等级徽章**、账号/连接状态、开关、更多菜单；底部说明 L1/L2 的含义与"不含 DRM 破解"。

**设计意图**：把"能不能播"提前说清楚，避免用户装上腾讯/优酷后才发现正片要跳官方 App。

### 06 播放
视频满窗 + 弹幕层 + 字幕层；顶部返回/标题/来源徽标；底部：章节化进度条、时间、播放/上下集/音量、弹幕/字幕/倍速、清晰度、剧集抽屉、全屏。

**交互（原型已实现）**：播放/暂停、点进度条跳转、弹幕开关、字幕开关、倍速循环、剧集抽屉切集、Esc 返回、Space 播放、←→ 5 秒。鼠标静止 3.2s 控制条淡出。

## 与 MyGo 原生 UI 的映射

| 界面元素 | MyGo 实现 |
| --- | --- |
| 侧栏 | `ui.Column` + 自定义 `navItem`，宽 232 |
| 玻璃顶栏/播放条 | `plugins/glass` 的 `ScrollEdge` / `Material` |
| 海报网格 | `ui.GridView` + 虚拟化；图片用 `ui.Image` + 异步 `artCache` |
| 首页大卡 | `ui.Box` + `Painter` 绘制光晕/渐变 + `ui.Video`（可选预告片） |
| 分集列表 | `ui.List` + 自定义行；进度条用 `ui.Box` 绘制 |
| 播放页 | `ui.Video(c, player).Fill()` + `DrawOver` 画弹幕/字幕 + 浮动控制条 |
| 弹幕 | `Painter.Text` 逐条绘制，或 `ui.Canvas`；时间基准 `player.Position()` |
| 字幕 | 底部安全区 `Painter.RichText`，支持双语两条 |
| 剧集抽屉 | `ui.Box` 绝对定位 + `AnimateTo` 位移 |
| 源卡片 | `ui.List` 行 + `ui.Switch` + 能力徽章（自定义 badge） |
| 进度条 | 自绘 `Painter.Fill` + 拖拽手势（`Press/Move/Release`） |
